# Call Center Multiplayer Mobile

React Native + Expo mobile version of the Call Center Multiplayer game.

## Roles
- Agent
- Quality
- Team Leader

## Multiplayer
The mobile app will reuse the existing Supabase backend and room model from the web game.

## First milestone
- Native Expo shell
- Create Room / Join Room
- Role selection
- Waiting room
- Shared player list
- Android-first UI

## Run

```bash
npm install
npx expo start
```
